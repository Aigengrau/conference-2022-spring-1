# Конференция «Юридическое онлайн-образование» (июль 2022)

Одностраничный сайт, перенесённый с Tilda на современный статический стек.
Оригинальный экспорт Tilda сохранён в [`original/`](./original) и служит
эталоном, с которым сверялась вёрстка.

| | |
|---|---|
| **Стек** | [Astro 5](https://astro.build) · TypeScript |
| **Рендеринг** | статическая генерация, ноль фреймворков на клиенте |
| **Блоков** | 11 |
| **Изображений** | 22 (2.6 МБ) |
| **JS от Tilda** | не осталось |

---

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # сборка в dist/
npm run preview
npm run check    # проверка типов
```

## Как устроено

```
src/
├── data/page.json     # разметка блоков, мета, список стилей
├── layouts/Base.astro # <head> и весь рантайм
├── styles/base.css    # то, что Tilda досчитывала скриптами
└── pages/index.astro
public/
├── styles/*.css       # 4 таблицы стилей — дизайн-спецификация
└── assets/img/*
```

Стили Tilda оставлены как есть: это скомпилированная под конкретно эти блоки
спецификация дизайна, и переписывать её вручную значило бы вносить ошибки.
А вот весь JavaScript Tilda выброшен — вместо него небольшой рантайм
в `Base.astro`, воспроизводящий ровно то, что делали её скрипты:
ленивые изображения, видео, анимации появления, cookie-баннер, вертикальное центрирование в zero-блоках.

## Точность переноса

Обе версии открывались в одном браузере при окне 1280×900, после чего
сравнивались первый экран и полная высота документа.

- **Первый экран:** расхождение 7.6 % — четыре элемента в шапке ниже на 23 px
- **Высота страницы:** совпадает точно (9669 px)

Полностраничные скриншоты для сверки не годятся: часть элементов позиционируется
в единицах `vh`, и в окне высотой 7000 px разъезжается сам оригинал.

### Что чинилось по дороге

1. **Шрифты.** Экспорт подключает Montserrat с Google Fonts отдельным
   `<link>`, который легко потерять — тогда всё откатывается на Arial,
   меняются метрики и переносы строк. На одной странице из-за этого текстовый
   блок вырастал на 302 px, а вся страница отличалась по высоте на 3 %.
2. **Вертикальное центрирование.** Zero-блоки экспортируются как
   `top: calc(50vh - 0px + 45px)`, где `0px` — заглушка: скрипт Tilda
   подставлял туда половину высоты элемента. Без этого блоки съезжали вниз.
3. **Cookie-баннер.** Приходит с классом `t886_closed` (`display:none`);
   показывать его и запоминать согласие должен был скрипт.
4. **Межстрочный интервал.** Tilda округляла `font-size × line-height`
   до целых пикселей перед отрисовкой.

## Деплой

GitHub Pages через Actions ([`deploy.yml`](./.github/workflows/deploy.yml)):

1. Запушить ветку `main`.
2. **Settings → Pages → Source: GitHub Actions.**

Если раздел Pages в репозитории ещё ни разу не включали, первый запуск упадёт
на шаге `Configure Pages`: токен воркфлоу умеет переключать источник, но не
создавать сайт с нуля. Включите Pages один раз руками — дальше всё само.

Свой домен: файл `public/CNAME` с одной строкой и DNS-записи GitHub.
